# صور المشروع

ضعي صور الأتيليه الحقيقية هنا بنفس الأسماء التالية، وستظهر تلقائيًا في الموقع.
حتى ذلك الحين يعرض الموقع إطارًا بديلًا بهوية العلامة — ولا يعرض أي صور جاهزة
على أنها من أعمال «أم علي».

الصيغة المفضلة: `.webp` (أو `.avif`). العرض المقترح بين ١٦٠٠ و٢٠٠٠ بكسل.

| الملف | الاستخدام | النسبة المقترحة |
| --- | --- | --- |
| `hero.webp` | خلفية القسم الرئيسي | عريضة 16:9 أو أوسع |
| `about.webp` | صورة قسم «من نحن» | طولية 4:5 |
| `fabric.webp` | خلفية قسم «تواصل معنا» | عريضة 16:9 |
| `service-tailoring.webp` | خدمة: تفصيل الملابس | 4:3 |
| `service-custom.webp` | خدمة: الخياطة حسب الطلب | 4:3 |
| `service-alterations.webp` | خدمة: التعديلات | 4:3 |
| `service-occasions.webp` | خدمة: تجهيز المناسبات | 4:3 |
| `service-embroidery.webp` | خدمة: التطريز | 4:3 |
| `gallery-01.webp` … `gallery-09.webp` | معرض الأعمال | حسب `aspect` في `src/data/gallery.ts` |
| `instagram-01.webp` … `instagram-06.webp` | شبكة إنستقرام | مربعة 1:1 |
| `og-cover.png` | صورة المشاركة (Open Graph) | 1200×630 |

لتغيير الأسماء أو العناوين أو التصنيفات، عدّلي `src/data/gallery.ts`
و`src/data/services.ts` — لا حاجة لتعديل أي مكوّن.

## صور مؤقتة (زخرفية)

السبع صور التالية موجودة حاليًا كصور **عامة مؤقتة** من [Pexels](https://www.pexels.com/license/)
(مجانية للاستخدام التجاري، لا تتطلب إسنادًا). الغرض منها زخرفي فقط: النصوص البديلة
لا تنسبها إلى أعمال «أم علي». استبدليها بصور الأتيليه الحقيقية بنفس الأسماء.

| الملف | Pexels ID | الوصف |
| --- | --- | --- |
| `hero.webp` | 3965543 | أقمشة على رفوف ورشة خياطة |
| `fabric.webp` | 15937623 | بكرات خيوط بلون ذهبي |
| `service-tailoring.webp` | 7147578 | رسم باترون على القماش |
| `service-custom.webp` | 7147642 | خياطة على الماكينة |
| `service-alterations.webp` | 8030153 | تثبيت القماش بالدبابيس على المانيكان |
| `service-occasions.webp` | 4982191 | فستان مناسبات على المانيكان |
| `service-embroidery.webp` | 9850825 | تطريز بخيوط ذهبية |

خانات المعرض وإنستقرام و`about.webp` **متروكة عمدًا** بالإطار البديل: النصوص المحيطة
بها تُعرّفها بأنها من أعمال الأتيليه، فلا يصحّ ملؤها بصور جاهزة.
